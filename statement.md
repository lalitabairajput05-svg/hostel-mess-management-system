# Project Statement

## Problem Statement

Managing hostel mess records manually can make it difficult to keep track of students, meals taken, and mess bills. This project provides a simple Python program to manage these records.

## Scope of the Project

The project is used to add student details, view student records, mark meals, search for students, and calculate the mess bill based on the number of meals taken.

## Target Users

The system can be used by hostel mess staff or administrators to maintain basic student mess records.

## High-Level Features

- Add a student using room number, name, and mess type.
- View student details.
- Mark a meal for a student.
- Search for a student using the room number.
- Calculate the mess bill based on meals taken.
- Store student and meal records in a text file.
